# Model 候选仓提案

建议状态：按需复审，不提前建仓。

## 拟解决的问题

为多个 IP/验证环境共享的高层参考模型提供独立版本、测试向量和语言绑定，避免在 VIP、DV Common 或各 IP 中复制。

## 边界

- 拟负责：行为契约、参考实现、向量、数值容差、语言/API binding 和版本；
- 不负责：协议 VIP、产品 testbench、RTL、训练数据或工具 adapter；
- 仅被一个 IP 使用的模型继续留在该 IP 仓。

## 建仓触发与首个切片

同一模型被两个以上 IP 使用，且其版本/许可证/发布周期独立。首个切片必须在两个消费者上用相同 golden vectors 交叉验证，并给出精度、性能、确定性和许可证 Evidence。

## 需要的决策

Owner、支持语言、artifact 格式、与 Catalog/Lock 的关系及私有模型边界需由 ADR 确定。
