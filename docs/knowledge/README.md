# Knowledge 仓设计契约

Knowledge 仓保存芯片研发方法论、术语、参考资料、案例和可检索索引。Owner 为 `engineering-platform`；工程师和 Skills 是消费者。它不拥有接口、版本、状态、Gate 或项目决策事实。

## 内容模型

内容分为基础方法、流程/交付、设计、验证、实现/签核、安全可靠性、工具自动化、AI 辅助和完整案例。18 卷目录是长期分类，不等于 18 卷同时承诺完成；活动建设以真实工程路径驱动。

每个条目必须含稳定 ID、Owner/Reviewer、适用范围、来源/许可证、版本/更新时间、关联资产/ADR、技术验证方式和敏感级别。外部资料优先保存元数据、摘要和合法获取方式，不默认复制受版权保护原文。

## 建设顺序

1. 先冻结术语、metadata、来源/许可证和检索索引；
2. 以 APB 寄存器 IP 路径验证“需求→设计→验证→Evidence→Release”知识链；
3. 以 MAC 案例验证 PPA/RTM/评审模板；
4. 再按用户反馈和项目复用扩充卷册，不以篇数替代质量。

## 验收出口

- 每个活动主题有 Owner/Reviewer、来源、技术验证和下次复审日期；
- 术语与工程 Schema/ADR 有链接但不复制事实；
- 搜索能从任务定位到方法、模板、案例和权威外部来源；
- 过期、断链、重复、许可证和敏感信息检查可运行；
- Skills 引用精确版本，Knowledge 缺失不改变确定性 Gate。
